# Prompt — Módulo 4, Video 15: La pantalla de input

**Módulo:** 04 — Frontend: La Interfaz
**Video:** 15 — La pantalla de input: capturar la idea del producto

---

## Prompt

```
Crea el componente SpecForm en /components/SpecForm.tsx.

Debe incluir:

1) Un textarea grande con placeholder 'Describe tu idea de producto... Por ejemplo: una app para que freelancers gestionen sus facturas'.

2) Un botón 'Generar especificación' debajo del textarea.

3) Mientras se genera, el botón debe mostrar un spinner y texto 'Generando...' y el textarea debe desactivarse.

4) Cuando termine, debe llamar a una función onResult con la spec generada.

5) Si hay error, mostrar un mensaje de error debajo del formulario.

6) Estilos con Tailwind CSS: diseño limpio, centrado, profesional.

Revisa el CLAUDE.md para contexto.
```
