# Prompt — Módulo 4, Video 16: La pantalla de output

**Módulo:** 04 — Frontend: La Interfaz
**Video:** 16 — La pantalla de output: mostrar la especificación generada

---

## Prompt

```
Crea el componente SpecOutput en /components/SpecOutput.tsx.
Recibe como prop un objeto spec con 6 secciones (vision, users, features, flows, architecture, requirements).

Debe mostrar:

1) Cada sección con un título destacado, un icono identificador y el contenido formateado.
2) La visión en un bloque destacado en la parte superior.
3) Usuarios como cards con sus casos de uso.
4) Funcionalidades como lista organizada por áreas.
5) Flujos como pasos numerados con indicador de flujo principal y flujo de error.
6) Arquitectura con la lista de tecnologías y el flujo de datos.
7) Requisitos divididos en incluidos y excluidos.
8) Un botón 'Copiar especificación completa' al final que copie todo al portapapeles como texto.
9) Animación suave de aparición cuando el resultado carga.
10) Estilos con Tailwind CSS.

Revisa el CLAUDE.md para contexto.
```
